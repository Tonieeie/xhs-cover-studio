# Skill: WeUp 小红书封面生成器（Wave Frame · 黄黑波浪框）

## 目标
用户给 AI 一张图片，AI 用固定模板（`cover-template.html`）生成一张统一风格的 WeUp 小红书封面。
**核心约束：除了那张图片，任何视觉元素都不能改。**

---

## 风格说明（Signature Look）
- **上三分之一是黄色区**（`#FFC524`，取自 logo 背景）——左上角放 WeUp logo，下方留白给用户自己打标题文字。
- 黄色区与图片之间的分割线是 **波浪形**，由珊瑚色（`#FF6F61`，取自 logo 里的圆点）缝线描出，绝不是直线。
- 用户图片填在下方，**cover-fit 居中裁剪、永不被压缩变形**；图片边缘被上方黄色波浪与下方深色波浪带 **自然盖住**。
- 最下面是 **深色波浪边框带**（`#1A1610`），带一条黄色发丝线和一个珊瑚色圆点点缀。
- 四周一圈黄色边框 → 黄黑组合的边框感。

---

## 输入
- 一张用户图片（任何长宽比、任何来源）。
- 上方黄色区与下方深色带都留给用户后期加文字/元素，模板本身不写字（只放 logo）。

## 输出
- 一张 **1200 × 1600 px**（3:4）的 PNG，作为小红书封面。

---

## 模板文件
- `cover-template.html` — 主模板（Wave Frame · 黄黑波浪框），用内嵌 canvas 脚本渲染。
- `cover-template-variants.html` — **多变体合集**：一个文件里四种黄黑版式，改顶部 `LAYOUT` 一个常量即可切换。
- `assets/logo.png` — WeUp 品牌 Logo（永远不动）。
- `assets/photo.jpg` — 当前封面用的图（每次被替换）。

---

## 变体 / Variants（都保持黄黑风格）

| LAYOUT | 名称 | 说明 |
|---|---|---|
| `wave` | Wave Frame | 上 1/3 黄区 + 波浪分割 + 底部深色波浪带。**默认**。 |
| `slant` | Slant 斜切 | 黄色顶区斜线收口（珊瑚缝）+ 反向深色斜带页脚，更有动感。 |
| `arch` | Arch Window 拱窗 | 图片放进圆拱窗口，黄底 + 深色描边 + 珊瑚内线，杂志感。 |
| `bottomwave` | Bottom Wave 大图 | 图片当主角铺满上方，底部黄色波浪带放 logo + 文案 + 深色页脚。 |

四种都遵循同一规则：图片 **cover-fit 不压缩**、被品牌形状自然盖住；黄色区留白给用户后期打标题。
切换方法：打开 `cover-template-variants.html`，把顶部 `const LAYOUT = 'wave'` 改成想要的值。
网页版工作室 `../index.html` 里这四种都已内置成独立卡片，拖图即可预览/下载。

---

## AI 执行流程

### Step 1. 接收用户图片
把用户提供的图片保存为 `assets/photo.jpg`（覆盖旧文件）。

### Step 2. 检查模板
打开 `cover-template.html`，确认：
- `PHOTO_SRC` 指向 `'assets/photo.jpg'`
- `WEUP` 配置里的其他值 **完全不动**（除非用户明确要求调整）。

### Step 3. 渲染并导出
- 在浏览器/无头浏览器里加载 `cover-template.html`
- 截取 `#cover` 这张 canvas，分辨率 **1200 × 1600**
- 保存为 PNG，命名：`output/cover-{timestamp}.png`

### Step 4. 交付
把成品图返回给用户。

---

## 严格的“不要做”清单

AI 在执行此 skill 时**绝对不可以**：

1. ❌ 改黄色/深色/珊瑚色配色
2. ❌ 改波浪的振幅、周期、相位（让波浪变直或乱跳）
3. ❌ 改 Logo 的位置或大小
4. ❌ 改边框厚度、顶部黄区高度、底部波浪带高度
5. ❌ 改 canvas 尺寸或长宽比
6. ❌ 替用户在黄色区/底部带里加标题文字（那是留给用户的空间）
7. ❌ 给图片加滤镜、调色，或把图片拉伸压缩
8. ❌ “优化”或“改进”模板

**唯一允许做的事：换 `PHOTO_SRC` 指向的图片。**

---

## 用户可显式请求的调整（仅当明确要求时）

都是 `cover-template.html` 里 `WEUP` 对象上的值，改值不改规则：

| 键 | 默认 | 含义 |
|---|---|---|
| `YELLOW` | `#FFC524` | 品牌黄（顶部区 + 边框） |
| `DARK` | `#1A1610` | 品牌近黑（底部波浪带） |
| `CORAL` | `#FF6F61` | 珊瑚色点缀（缝线 + 圆点） |
| `BORDER` | `22` | 四周黄色边框厚度（px） |
| `TOP_WAVE_Y` | `0.355` | 顶部分割线中线（占高度的比例） |
| `TOP_WAVE_AMP` | `48` | 顶部波浪振幅 |
| `TOP_WAVE_CYCLES` | `1.5` | 顶部波浪在宽度上的周期数 |
| `BOTTOM_BAND` | `176` | 底部深色波浪带高度（px） |
| `BOTTOM_WAVE_AMP` | `34` | 底部波浪振幅 |
| `SEAM` | `12` | 顶部珊瑚色缝线粗细 |
| `LOGO_SIZE` | `248` | Logo 尺寸 |
| `LOGO_X` / `LOGO_Y` | `34` / `24` | Logo 距内边框的左/上偏移 |

## 测试用例

### 用例 1：基本调用
> 用户：“给这张图做一个 WeUp 封面” + [一张图]

→ AI：保存图到 `assets/photo.jpg` → 渲染 → 导出 1200×1600 PNG。

### 用例 2：用户要求改
> 用户：“顶部黄色区再高一点”

→ AI：把 `TOP_WAVE_Y` 从 `0.355` 调到比如 `0.40`。**不改其他任何东西。**
