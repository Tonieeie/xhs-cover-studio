Cover Frame System · 小红书封面 · 3:4

三种统一封面框 — BrandPulse Media

核心思路：每张封面都是「一张图 + 一套固定的边框」。所有帖子套同一个框，刷到主页就能立刻认出是你的内容。下面三种风格各自有完整的视觉逻辑、Logo 处理方式和占位结构，挑一个稳定用即可。

Editorial Border

心理逻辑
"杂志感 / 收藏感"。米色纸感底 + 内嵌细线框 + 四角刻度，让每张图看起来像被「装裱」过。适合分享审美、生活方式、品牌灵感类内容。吸引追求质感、慢节奏、文艺向的用户。
Logo 处理
底部居右，32px 缩略 Logo + 衬线字 BRANDPULSE。无阴影、无混合模式，直接平铺在米色纸上。比例约占封面宽度 1/4，永远固定位置。
占位结构
外层：米色画框（左右上 32px，下 114px）。
主体：图片居中嵌入框内。
四角：1px 实心刻度小方块。
底栏：左 = 编号 / 栏目，右 = Logo 锁定位。
Frame · 02
L-Bracket Half Frame
取景器 · 对角半框
Your Photo · Full Bleed
Brandpulse
心理逻辑
"取景框 / 镜头感"。图片满铺，左上 + 右下两个白色 L 形角标，像相机取景框，暗示「这是我捕捉的一刻」。专业感、冷感、当代。吸引关注摄影、时尚、商业洞察、行业分析的用户。
Logo 处理
右下角小尺寸圆形裁切 + 白色衬线字。滤镜：grayscale(1) + brightness(1.4)，让 Logo 在任何底图上都呈现统一的白色调。上下加渐变保护层确保可读性。
占位结构
主体：图片满铺铺底。
顶 / 底：黑色保护渐变（28% / 40% 高度）。
左上：L 角 + 横线 + 栏目编号。
右下：圆形 Logo + 衬线名。
L 角永远固定 28px 内缩、140×140 尺寸。

心理逻辑
"档案 / 期刊感"。顶部黑条 + 底部米白条，像一本期刊或档案卡片。每期换图但版式不变，主页瀑布流刷下来会形成强烈的「系列感」。适合知识、合集、连载型内容。吸引爱收藏、爱归档、有品牌意识的人群。
Logo 处理
底部白栏左侧 62×62 方形 Logo + 衬线名。Logo 直接使用原图（深底 + 白天鹅），与上方黑条呼应，无需任何混合模式。永远占据底栏左半。
占位结构
顶栏（60px）：左 = 刊名 / 栏目，右 = 期号。
主体：图片满铺中段（60–下 150 之间）。
底栏（150px）：左 = Logo + 名称，右 = 编号 + 日期。
三段比例固定，换图不换框。

怎么用：选定一种之后，每次发帖只换中间的图片就行，外层的边框、Logo、字号、颜色、位置全部保持不变。建议在 Figma / Canva / 醒图里做一个固定模板，导入图片即可一键出图，几个月不变形 —— 这就是「视觉资产积累」。
